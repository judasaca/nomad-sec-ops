# Repository instructions

## Review the security policies after every task

Before completing any task, review the security policy documents in `docs/`
against the repository's current behavior, defaults, and planned features.
Check whether the task made any policy inaccurate or obsolete.

If a policy needs to be updated or retired, tell the user which document is
affected, why it needs to change, and what wording or removal you propose. Ask
for approval before editing or removing the policy. An explicit request from
the user to make that specific policy change counts as approval.
